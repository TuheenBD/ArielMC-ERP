# ArielMC Brand Rules & Nomenclature

## Official Brand Name
- **Always write **ArielMC** (Bold) in this way.**
- Capital `A`, lowercase `riel`, uppercase `MC`, no spaces: **ArielMC**.
- **NEVER** mention or write:
  - `Ariel`
  - `Arialmc`
  - `Ariel MC`
  - `Arial mc`
- When referring to the company entity: **ArielMC** (or "Ariel Marketing & Communications Limited" for statutory corporate filings).
- Applicable to all UI copy, documentation, commit messages, code comments, system notifications, templates, and communications.
